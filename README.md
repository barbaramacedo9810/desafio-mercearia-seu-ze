# Desafio Mercearia do Seu Zé

## Sobre o projeto

Este projeto foi desenvolvido para criar uma página simples para a
Mercearia do Seu Zé.

A proposta é facilitar o acesso às principais informações da mercearia,
como endereço, horário de funcionamento, formas de contato, produtos e
promoções.

A página foi desenvolvida utilizando HTML5 e tags semânticas aprendidas
durante as aulas.
